# RentHumanoid

Marketing site for RentHumanoid — humanoids for hire, dispatched daily.

- `site/` — the live site (plain static HTML, no build step). Deploy this folder.
- `concepts/` — the five original design directions (C "Dispatch" was chosen).

Live: https://renthumanoid.netlify.app/ — Netlify deploys `site/` on every push to `main` (see `netlify.toml`).

Preview locally: open `site/index.html` in a browser, or `python3 -m http.server -d site`.
